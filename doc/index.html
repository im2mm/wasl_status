WASL Status

PILOT Extension wasl_status · version 1.0.0

Lists every vehicle of a PILOT account with its WASL connection, using the same values PILOT shows in the WASL and WASL STATE columns of the Online list.

Using it

  1. Click the WASL Status icon on PILOT's left bar.
  2. Choose Current account (the account you are signed in with) or Another account and enter its login and password.
  3. The list shows every vehicle. Use the filter (All / Connected / Not connected), the search box, Refresh, Change account and Export CSV.

Columns

ColumnMeaning
Vehicle, Plate, GroupObject name, plate (object info) and the folder it is in.
WASLLast time WASL accepted data for the vehicle. Green when it is less than 1 hour old, red when older (same rule as PILOT). Hover for the age.
WASL StateConnected when WASL returned a state for the vehicle, otherwise Not connected.
WASL ResponseThe state WASL returned, for example MOVING, PARKED_ENGINE_ON, PARKED_ENGINE_OFF, DEVICE_NO_SIGNAL, DEVICE_NOT_WORKING.

Another account and your session

For Another account the sign-in is done by the extension's backend (api/wasl.js), not by your browser, so your own PILOT session is not switched. The backend signs in, reads the list, signs out and keeps nothing. The password stays in the page's memory only, so Refresh works until PILOT is reloaded. Accounts with two-factor sign-in are not supported.

Times are shown with PILOT's own date format (account time zone); the CSV export uses the same text. Vehicles not registered in WASL simply have no WASL time and are Not connected.

Installation

  1. Deploy this folder to Vercel (static files plus the api/wasl.js function, Node 22).
  2. Check that https://<your-project>.vercel.app/Module.js opens as JavaScript.
  3. PILOT Admin → Extensions: name wasl_status, URL https://<your-project>.vercel.app/ (base URL, trailing slash).
  4. Grant the extension to the accounts that need it, then reload PILOT.

The extension calls its backend at /store/wasl_status/api/wasl (PILOT's same-origin proxy). If the files are hosted somewhere without the function (for example GitHub Pages), set the extension setting api_url to the full backend address, for example https://<your-project>.vercel.app/api/wasl. The backend allows calls from *.pilot-gps.com only and signs in only to *.pilot-gps.com hosts.

Troubleshooting

  • "PILOT session is not signed in" – reload PILOT and sign in again.
  • "The WASL Status backend is not reachable" – the backend is not deployed at the registered URL; set api_url.
  • "Invalid Login or Password" – the message comes from PILOT for the other account.
  • All vehicles Not connected – the account has no WASL module, or PILOT has not received WASL answers yet.
